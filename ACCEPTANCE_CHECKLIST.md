# Чек-лист приёмки доработки

## Мюнстерберг
- [ ] Целевые слова отмечаются нажатием на текст; ручного ввода списка нет.
- [ ] Все целевые слова не короче 5 букв.
- [ ] На каждом уровне правильное количество строк и целевых слов.
- [ ] На широком экране массив выглядит как длинные строки и центрирован.
- [ ] Повторное нажатие не добавляет очки повторно; новая игра генерирует новый набор.

## Шульте
- [ ] Игровое поле не сдвигается и не вызывает вертикальную прокрутку при ответах.
- [ ] Есть 5×5/7×7, цифры/латиница/кириллица, цветной/чёрно-белый режим, прямой/обратный порядок.
- [ ] Русские буквы включают Ё; целевая последовательность непрерывна.
- [ ] Размер символа выбирается и виден в живом предпросмотре.
- [ ] Цвета различимы, без градиентов и похожих оттенков.
- [ ] Сессии на 1–5 минут засчитывают только полностью пройденные таблицы.

## Совпадение цвета
- [ ] Правая карточка содержит слово, напечатанное цветными буквами; левая — название цвета.
- [ ] Ответ «Да» определяется сравнением слова слева с фактическим цветом шрифта справа.
- [ ] Используется только палитра радуги плюс розовый.
- [ ] Таймер 1–3 минуты, ответы, счётчик ошибок и история работают.

## Книги и чтение
- [ ] EPUB, DOCX, TXT импортируются локально, пользовательские документы не отправляются на сервер.
- [ ] Книга листается страницами/главами, доступна навигация назад/вперёд.
- [ ] Можно коснуться последнего прочитанного слова и завершить замер на нём.
- [ ] WPM учитывает слова от стартовой позиции до конечного слова и реальное время.
- [ ] После перезагрузки сохранены книга и позиция чтения.

## Мнемотаблица
- [ ] Поле 5×5 на лёгком уровне содержит ровно 9 активных разных элементов.
- [ ] На сложном/максимальном уровне не уменьшена сложность по сравнению с существующим вариантом.
- [ ] Восстановление позиции и цвета доступно через сенсорный сценарий.

## Треугольное поле
- [ ] 99 треугольных ячеек, уникальные числа 1–99.
- [ ] При каждом новом раунде числа и четыре цвета распределены заново.
- [ ] В ходе раунда раскладка остаётся стабильной.
- [ ] Есть режимы обратного таймера 1–5 минут и «До конца» с секундомером.
- [ ] Поиск идёт по порядку 1–99; ошибки учитываются.

## Регрессии и выпуск
- [ ] Старые функции продолжают работать, старая история не удалена.
- [ ] Сохранение локальное через LocalStorage/IndexedDB, без авторизации и backend.
- [ ] Таймеры корректны при переключении вкладки.
- [ ] Unit-тесты/lint/typecheck/build запущены; в отчёте указаны фактические результаты.
- [ ] GitHub Pages публикуется с корректным base path.
