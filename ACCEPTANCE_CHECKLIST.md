# ACCEPTANCE_CHECKLIST.md — ручная проверка после реализации

Проверяй в опубликованной версии сайта на iPad Safari и, по возможности, в десктопном браузере. Отмечай только то, что проверено фактически.

## Существующая версия
- [ ] Сайт открывается через GitHub Pages без ошибки загрузки.
- [ ] Главная и существующие функции первого этапа доступны.
- [ ] Обновление страницы не ломает навигацию.
- [ ] В приложении нет экранов регистрации/логина и требований подключить Supabase.

## Мюнстерберг
- [ ] Лёгкий: 30 строк, 5 слов.
- [ ] Средний: 40 строк, 8 слов.
- [ ] Сложный: 50 строк, 11 слов.
- [ ] Эксперт: 60 строк, 15 слов.
- [ ] Слова визуально не выделены; ввод правильных слов засчитывается без дубликатов.
- [ ] Повторный старт генерирует другой текст.

## Игра памяти слов
- [ ] Можно задать от 5 до 50 слов.
- [ ] Можно выбрать 1, 2 или 3 минуты.
- [ ] Список расположен столбцом и скрывается в ноль секунд.
- [ ] Результат перечисляет правильные, забытые и лишние слова.
- [ ] Повторные слова в одном наборе не появляются.

## Чтение и импорт
- [ ] Новая встроенная тренировка выдаёт новый текст.
- [ ] Использованный встроенный текст не повторяется до исчерпания коллекции.
- [ ] Загружается EPUB.
- [ ] Загружается Word DOCX.
- [ ] Загружается TXT.
- [ ] `.doc` отклоняется с понятной инструкцией.
- [ ] После обновления страницы импортированная книга остаётся в «Моих книгах».
- [ ] Можно продолжить чтение с сохранённой позиции.
- [ ] Файл не отправляется на сервер.

## Шульте
- [ ] Числа и латиница по-прежнему работают.
- [ ] Русские буквы включают `Ё`.
- [ ] Есть размеры 5×5 и 7×7.
- [ ] Для 7×7 все 49 целей уникальны.
- [ ] Чёрно-белый и цветной режимы работают во всех режимах символов.

## Мнемотаблица
- [ ] Сетка 5×5.
- [ ] Уровни имеют 9/16/25/25 активных элементов и палитры 3/4/6/8 цветов.
- [ ] Таймер запоминания позволяет выбрать 1–5 минут.
- [ ] По истечении таймера оригинальное цветное поле больше не отображается.
- [ ] Чёрно-белые элементы можно раскладывать касанием на iPad.
- [ ] Можно указать цвет каждого элемента и исправлять расстановку.
- [ ] Отдельно показываются точность положения и точность цвета.

## Алфавитная игра
- [ ] Есть все 33 буквы русского алфавита, включая `Ё`, `Ъ`, `Ы`, `Ь`.
- [ ] Есть последовательное прохождение и самостоятельный выбор буквы.
- [ ] Для каждой буквы показаны все 12 категорий по одной карточке.
- [ ] Таймер начинается на первой карточке и останавливается после последней.
- [ ] Пропуск возможен для трудной/невозможной категории.
- [ ] Неподходящая начальная буква приводит к предупреждению.
- [ ] После завершения буква недоступна повторно в тот же локальный день.
- [ ] Другие ещё не завершённые буквы остаются доступны.
- [ ] При обновлении страницы активная сессия и таймер не обнуляются.

## История и техническое качество
- [ ] Все шесть типов тренировки появляются в истории.
- [ ] История сохраняется после обновления страницы.
- [ ] Длинный текст книг хранится в IndexedDB, а не в localStorage.
- [ ] Production-сборка проходит.
- [ ] Тесты/lint/typecheck пройдены или отсутствующие проверки описаны в отчёте.
- [ ] Ссылка GitHub Pages открывается после публикации, base path не сломан.
