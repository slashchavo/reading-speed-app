# Прототип приложения по скорочтению — стартовый пакет

Этот пакет нужен, чтобы запустить разработку MVP через Claude Code.

## Что лежит в пакете

- `PRODUCT.md` — идея продукта, пользователи, экраны и границы MVP.
- `TECH_SPEC.md` — подробное функциональное и техническое ТЗ, данные и критерии приёмки.
- `CLAUDE.md` — постоянные инструкции для Claude Code в рамках этого проекта.
- `FIRST_TASK.md` — первый запрос для Claude Code и план последующих итераций.

## Как использовать

1. Создай папку проекта, например `reading-speed-app`.
2. Помести эти четыре файла в корень папки проекта.
3. Открой терминал в этой папке и запусти `claude`.
4. Скопируй запрос из `FIRST_TASK.md` в Claude Code.
5. Читай предлагаемые изменения и команды перед подтверждением. Не соглашайся на удаление файлов, публикацию секретов или развёртывание в интернете, если не понимаешь, зачем это нужно.

## Предлагаемый стек

Vite + React + TypeScript + обычный CSS. На первом этапе — только браузер, без сервера и регистрации. Результаты хранятся локально в `localStorage` на этом устройстве.
