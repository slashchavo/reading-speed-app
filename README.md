# «Фокус» — прототип приложения для тренировки чтения и внимания

Статический веб-прототип без сервера и регистрации. Всё работает в браузере, результаты хранятся локально на устройстве.

## Что умеет приложение

| Раздел | Что внутри |
| --- | --- |
| **Чтение** | 32 оригинальных текста (300+ слов), каждый раз новый — без повторов, пока библиотека не прочитана. Свой текст (вставка или `.txt`). Размер шрифта, слова в минуту. |
| **Мои книги** | Загрузка EPUB, DOCX и TXT (до 30 МБ), разбор прямо в браузере. Листание страниц (кнопки, свайп, стрелки), главы, замер скорости до слова, которого коснулись; место и последнее слово сохраняются. |
| **Таблица Шульте** | Сессия 1–5 минут из последовательных таблиц. 5×5 и 7×7; числа, латиница, кириллица (5×5 — 25 букв подряд от случайной, 7×7 — все 33 буквы и 16 пустых клеток); прямой/обратный порядок; цветной/чёрно-белый; 5 размеров символа; живой предпросмотр. Во время сессии поле закреплено, страница не прокручивается. |
| **Тест Мюнстерберга** | 4 уровня: 30/5, 40/8, 50/11, 60/15 (строк/слов), слова от 5 букв. Слова отмечаются касанием прямо в тексте; строки 45–56 букв на широком экране, массив по центру. |
| **Совпадает ли цвет?** | Совпадает ли слово слева с цветом букв справа. 8 цветов (радуга + розовый), 1–3 минуты. |
| **Треугольное поле** | 99 треугольников с числами 1–99 в четырёх цветах; режимы «На время» (1–5 мин) и «До конца». |
| **Память на слова** | 5–50 слов, 1/2/3 минуты, затем ввод по памяти: верные, забытые и лишние слова. |
| **Мнемотаблица** | Поле 5×5, 4 уровня (9/16/25/25 элементов, 3/4/6/8 цветов), запоминание 1–5 минут, восстановление касаниями. Лёгкий уровень — 9 простых, заведомо разных фигур. |
| **От А до Я** | 33 буквы, 12 категорий, режимы «по порядку» и «выбрать букву», пройденная буква открывается на следующий день. |
| **Прогресс** | История всех тренировок, метрики по каждому виду, резервная копия в JSON. |

## Важно про хранение данных

- История, настройки, отметки букв и использованные тексты — в `localStorage` браузера.
- Загруженные книги (извлечённый текст и место чтения) — в IndexedDB браузера.
- Данные **не синхронизируются** между устройствами и браузерами и пропадут при очистке данных сайта. Для переноса истории есть «Прогресс → Сохранить копию (JSON)». Книги в копию не входят — их можно загрузить снова.
- Файлы книг не отправляются в интернет: разбор идёт на устройстве.
- Блокировка букв в игре «От А до Я» работает только в этом браузере; это не защищённое серверное ограничение.

Ключи `localStorage`:

| Ключ | Что хранит |
| --- | --- |
| `focus-app:sessions:v1` | История тренировок (формат первого этапа сохранён, новые типы добавлены в тот же список) |
| `focus-app:settings:v1` | Настройки: шрифт, параметры игр |
| `focus-app:used-texts:v1` | ID прочитанных встроенных текстов |
| `focus-app:memory-recent:v1` | Последние 20 наборов слов игры на память |
| `focus-app:alphabet:v1` | Даты прохождения букв и активная незавершённая игра |

IndexedDB: база `focus-app-books`, хранилища `books` (метаданные) и `contents` (текст).

## Что нужно установить

- [Node.js](https://nodejs.org/) версии **20.19+ или 22.12+** (рекомендуется LTS). Проверить: `node -v`.

## Запуск

```bash
npm install      # один раз: установить зависимости
npm run dev      # запустить в режиме разработки
```

Откройте адрес, который покажет терминал (обычно http://localhost:5173).

### Открыть на iPad или телефоне

1. Компьютер и iPad должны быть в **одной Wi-Fi сети**.
2. На компьютере выполните `npm run dev:ipad`.
3. В терминале появится строка `Network: http://192.168.x.x:5173/` — откройте этот адрес в Safari на iPad.
4. Если не открывается — разрешите Node.js входящие подключения в файрволе компьютера.

### Публикация на GitHub Pages

Сборка и публикация настроены в `.github/workflows/deploy-pages.yml` и запускаются при каждом изменении ветки `main`
(тесты → сборка → публикация). Включить один раз: репозиторий на GitHub → **Settings → Pages → Source: GitHub Actions**.
Адрес вида `https://<логин>.github.io/reading-speed-app/`. Сайт открыт всем, кто знает адрес.
`base: './'` в `vite.config.ts` позволяет открывать сборку из любой подпапки — не меняйте его.

## Другие команды

| Команда | Что делает |
| --- | --- |
| `npm run build` | Проверка TypeScript и сборка в папку `dist/` |
| `npm run typecheck` | Только проверка типов TypeScript |
| `npm test` | Автотесты логики (генераторы игр, проверка ответов, хранение, книги, тексты) |
| `npm run preview` | Запуск собранной версии из `dist/` (доступна и в локальной сети) |

Отдельного линтера (ESLint) в проекте нет; качество кода проверяют строгий TypeScript и тесты.

## Зависимости

- `react`, `react-dom` — интерфейс.
- `fflate` — распаковка ZIP (EPUB и DOCX — это ZIP-архивы с XML внутри). Маленькая библиотека без зависимостей; текст из XML достаётся встроенным в браузер DOMParser. Код разбора книг загружается отдельно, только при первом импорте.
- `vite`, `@vitejs/plugin-react`, `typescript` — сборка и проверка типов.
- `vitest` — автотесты чистых функций.

## Структура

```text
src/
  app/            App.tsx, useAppData.ts — корень приложения, история и настройки
  components/     Общие элементы: навигация, карточки, переключатели, списки слов
  pages/          Экраны разделов
  features/
    schulte/      Последовательности, порядок, палитра, размер символа, сессия, предпросмотр
    colorMatch/   «Совпадает ли цвет?»: пары, правило ответа
    triangle/     Треугольное поле: геометрия 99 ячеек, раскладка, порядок
    munsterberg/  Генератор шума со спрятанными словами, игра
    memory/       Наборы слов без повторов, игра
    mnemo/        Генерация поля, раскладка, оценка позиции и цвета, игра
    alphabet/     Категории, проверка первой буквы, дневная блокировка, игра
    library/      32 встроенных текста и выбор нового
    reader/       Замер скорости чтения (общий для текстов и книг)
    books/        Импорт EPUB/DOCX/TXT, IndexedDB, сквозная нумерация слов, страницы, замер до слова
    progress/     Сводка, история, резервная копия
    words/        Встроенный словарь (200+ слов)
  lib/            Хранение (localStorage), даты, таймеры, нормализация ответов, случайность
  types/          session.ts — типы записей истории и настроек
  styles/         global.css
```
