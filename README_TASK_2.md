# Этап 2 — как передать требования Claude Code

Этот архив предназначен для продолжения существующего проекта, опубликованного через GitHub Pages. Авторизация и backend намеренно исключены.

## Состав пакета
- `TASK_2_REQUIREMENTS.md` — полное функциональное ТЗ.
- `TASK_2_PROMPT_FOR_CLAUDE.md` — готовый промпт для Claude Code.
- `FILE_IMPORT_AND_STORAGE.md` — требования к EPUB/DOCX/TXT, IndexedDB, localStorage и таймерам.
- `ACCEPTANCE_CHECKLIST.md` — чек-лист ручной проверки MVP.

## Как загрузить с iPad
1. Скачай ZIP и распакуй его в приложении «Файлы».
2. Открой **существующий** репозиторий приложения на GitHub.
3. Выбери `Add file` → `Upload files`.
4. Загрузите пять файлов из папки архива в корень репозитория. Загружай файлы отдельно, не сам ZIP.
5. Не удаляй файлы первого этапа. Если в корне уже есть `README.md`, не заменяй его автоматически: `README_TASK_2.md` — отдельный файл.
6. Нажми `Commit changes`.
7. Открой Claude Code и выбери облачное окружение, связанное с тем же репозиторием.
8. Открой `TASK_2_PROMPT_FOR_CLAUDE.md`, скопируй промпт между разделителями `---` и отправь Claude.

## Что должно произойти
Claude сначала изучит текущий код и сообщит короткий план, после чего внесёт изменения в тот же проект. Он не должен создавать фиктивную авторизацию или подключать Supabase.

После реализации попроси/проверь:
- прошла ли production-сборка;
- работает ли GitHub Pages preview после публикации;
- какие тесты реально запускались;
- какие функции не готовы.

## Ограничения локального режима
Результаты и настройки сохраняются в браузере на текущем устройстве. Они не синхронизируются между устройствами и могут быть удалены при очистке данных сайта. Импортированные книги обрабатываются на устройстве и не отправляются на сервер.
