# Пакет правок для Claude Code — приложение «Фокус»

Этот пакет предназначен для доработки уже опубликованного прототипа. Он не является новой реализацией приложения.

## Содержимое

- `TASK_2_CHANGE_REQUESTS.md` — актуальные уточнения и новые функции; имеет приоритет при противоречиях.
- `TASK_2_REQUIREMENTS_BASE.md` — базовые требования второго этапа, сохранённые для функций, которые не отменены новыми правками.
- `FILE_IMPORT_AND_STORAGE.md` — подробности импорта книг и локального хранения.
- `TASK_2_PROMPT_FOR_CLAUDE.md` — готовый промпт для запуска работы в Claude Code.
- `ACCEPTANCE_CHECKLIST.md` — список проверок после реализации.

## Как использовать с iPad

1. Распакуйте архив в приложении «Файлы».
2. Загрузите документы в корень существующего GitHub-репозитория через `Add file → Upload files` и нажмите `Commit changes`. Не удаляйте файлы приложения.
3. Откройте существующее облачное окружение Claude Code, связанное с этим репозиторием.
4. Откройте и скопируйте весь текст `TASK_2_PROMPT_FOR_CLAUDE.md` в Claude Code.
5. Дождитесь аудита и изменений. Просмотрите список файлов и результаты проверок в итоговом сообщении Claude.
6. Если Claude подготовил изменения в ветке или PR, проверьте diff и только затем объединяйте его в основную ветку. После публикации GitHub Pages откройте сайт и проверьте чек-лист.

## Важно

- Авторизация, Supabase, backend и облачная синхронизация не входят в этот этап.
- Книги и история остаются на текущем устройстве/в том же браузере. Очистка данных сайта может удалить локальные результаты.
- `TASK_2_CHANGE_REQUESTS.md` заменяет устаревшие инструкции, если они противоречат новым пожеланиям.
