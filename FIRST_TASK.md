# FIRST_TASK.md — первый запрос для Claude Code

## Первый запрос (скопируй целиком в Claude Code)

Прочитай `CLAUDE.md`, `PRODUCT.md` и `TECH_SPEC.md` полностью. На их основе разработай MVP веб-приложения «Фокус».

Работай итерациями:

1. Сначала кратко опиши план реализации и предложи структуру файлов.
2. Затем создай приложение на Vite + React + TypeScript, если проект ещё не создан. Не перезаписывай существующие файлы без необходимости; сначала осмотри папку проекта.
3. Реализуй общий адаптивный интерфейс и навигацию между разделами «Главная», «Шульте», «Чтение» и «Прогресс».
4. Реализуй таблицы Шульте согласно `TECH_SPEC.md`.
5. Реализуй чтение демонстрационного или пользовательского текста, загрузку `.txt`, регулировку размера шрифта и расчёт слов в минуту.
6. Реализуй типизированное локальное хранение истории через `localStorage` и вывод результатов на экране «Прогресс».
7. Проверь требования и критерии приёмки из `TECH_SPEC.md`. Запусти доступные команды проверки и сборки, исправь обнаруженные ошибки.
8. Обнови `README.md` так, чтобы новичок смог запустить проект по инструкции.

Не пытайся реализовывать будущие функции, которых нет в MVP. Не подключай backend, API, авторизацию или платные сервисы. Не публикуй приложение в интернете.

После реализации выведи понятный отчёт на русском языке: что готово, какие команды проверки запускались и с каким результатом, как запустить приложение, что мне проверить вручную. Не заявляй, что всё работает, если не запускал соответствующую проверку.

## Если Claude сначала выдаст только план

Ответь: «План принимаю. Теперь реализуй MVP по согласованному плану и критериям приёмки из `TECH_SPEC.md`. После каждой крупной части проверяй, что проект собирается».

## Если Claude задаёт много вопросов

Ответь: «Для вопросов, не блокирующих работу, используй самые простые разумные значения согласно `PRODUCT.md` и `TECH_SPEC.md`, зафиксируй допущения и продолжай. Не добавляй функциональность вне MVP».

## План следующими итерациями

1. **MVP:** базовые экраны, Шульте, чтение, история.
2. **Полировка:** улучшение визуального дизайна, доступности и обработка граничных случаев.
3. **Проверка с пользователем:** собрать список неудобств и приоритетов.
4. **Следующие функции:** Мюнстерберг, периферическое зрение, импорт EPUB, мотивация и расширенная аналитика — только после тестирования MVP.
